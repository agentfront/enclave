# @enclave-vm/stream

Streaming protocol building blocks for the EnclaveJS runtime. Provides NDJSON serialization and parsing, reconnection helpers, and encryption primitives.

<Warning>
  No EnclaveJS package uses the encryption primitives. `@enclave-vm/client`, `@enclave-vm/react`, `@enclave-vm/broker` and `@enclave-vm/runtime` do not encrypt, perform no handshake and have no encryption option. A session between the client and the broker is plain JSON protected only by the transport, so serve it over HTTPS. See [Encryption Primitives](#encryption-primitives).
</Warning>

## Installation

```bash
npm install @enclave-vm/stream
```

## NDJSON Protocol

EnclaveJS uses NDJSON (Newline-Delimited JSON) for streaming events. Each line is a complete JSON object representing a stream event.

### Serialization

```typescript
import { serializeEvent, serializeEvents, type StreamEvent } from '@enclave-vm/stream';

const events: StreamEvent[] = [
  { protocolVersion: 2, sessionId: 's_abc123', seq: 1, type: 'stdout', payload: { chunk: 'Hello\n' } },
  { protocolVersion: 2, sessionId: 's_abc123', seq: 2, type: 'final', payload: { ok: true, result: 42 } },
];

// Serialize a single event (one line, no trailing newline)
const line = serializeEvent(events[0]);
// '{"protocolVersion":2,"sessionId":"s_abc123","seq":1,"type":"stdout","payload":{"chunk":"Hello\\n"}}'

// Serialize multiple events, joined with '\n'
const lines = serializeEvents(events);
```

### Parsing

Lines are validated against the event schemas of `@enclave-vm/types`.

```typescript
import { parseLine, parseLines, NdjsonStreamParser } from '@enclave-vm/stream';

// Parse a single line
const result = parseLine(line);
if (result.success) {
  console.log(result.data.type); // 'stdout'
} else {
  console.error(result.error);
}

// Parse multiple lines
const { events, errors } = parseLines(ndjsonString);

// Incremental stream parsing
const parser = new NdjsonStreamParser({
  onEvent: (event) => console.log('Received event:', event.type),
  onError: (error) => console.error(`Line ${error.line}: ${error.error}`),
});

// Feed chunks as they arrive; a chunk may end in the middle of a line
parser.feed('{"protocolVersion":2,"sessionId":"s_abc123",');
parser.feed('"seq":1,"type":"stdout","payload":{"chunk":"Hello\\n"}}\n');

// Flush what is left when the stream ends
parser.flush();
```

### Web Streams

```typescript
import {
  createNdjsonParseStream,
  createNdjsonSerializeStream,
  parseNdjsonStream,
} from '@enclave-vm/stream';

// TransformStream from text chunks to events
const parseStream = createNdjsonParseStream();

// TransformStream from events to lines
const serializeStream = createNdjsonSerializeStream();

// Async generator over a ReadableStream<Uint8Array>, such as a fetch() response body
const events = parseNdjsonStream(responseBody);
for await (const event of events) {
  console.log(event.type, event.payload);
}
```

`createNdjsonParseStream` and `parseNdjsonStream` skip a line that is not a valid event. Use `NdjsonStreamParser` to be told about such lines.

### Line Length Limit

The incremental parsers never hold more than `maxLineLength` characters of a line that has not ended. The default is `DEFAULT_MAX_LINE_LENGTH` (8 MiB).

```typescript
import {
  NdjsonStreamParser,
  NdjsonLineTooLongError,
  createNdjsonParseStream,
  parseNdjsonStream,
  DEFAULT_MAX_LINE_LENGTH, // 8 * 1024 * 1024
} from '@enclave-vm/stream';

const options = { maxLineLength: 1024 * 1024 };

// Reports the line once through onError, then skips it
const parser = new NdjsonStreamParser({ onEvent, onError, ...options });

// Both end with an NdjsonLineTooLongError
const parseStream = createNdjsonParseStream(options);
const events = parseNdjsonStream(responseBody, options);
```

A `maxLineLength` that is not a positive integer throws a `RangeError`.

## Encryption Primitives

The package exports the pieces of an encrypted channel: ECDH P-256 key exchange helpers, HKDF-SHA-256 key derivation, AES-256-GCM, and the `enc` envelope of the protocol.

<Warning>
  Nothing in EnclaveJS calls these functions, and `new EnclaveClient({ encryption })` throws. An application that wants payload encryption has to implement both ends itself, exchange the hello messages and the envelopes over its own endpoints, and keep using TLS. The [Encrypted Sessions](/examples/encrypted-sessions) example shows the wiring.
</Warning>

### Key Exchange (ECDH)

```typescript
import {
  generateKeyPair,
  createClientHello,
  processClientHello,
  processServerHello,
  deriveSharedSecret,
} from '@enclave-vm/stream';

// Client: generate an ephemeral P-256 key pair and create the hello
const clientKeys = await generateKeyPair();
const clientHello = await createClientHello(clientKeys);

// Server: process the client hello. This generates the server's key pair,
// a key id, and the server hello to send back.
const { serverKeyPair, peerPublicKey: clientPublicKey, serverHello, keyId } = await processClientHello(clientHello);
const serverSecret = await deriveSharedSecret(serverKeyPair.privateKey, clientPublicKey);

// Client: process the server hello
const { peerPublicKey: serverPublicKey } = await processServerHello(serverHello);
const clientSecret = await deriveSharedSecret(clientKeys.privateKey, serverPublicKey);

// Both now have the same shared secret
```

`generateKeyPair` returns a private key that cannot be exported. `processClientHello` and `processServerHello` throw `EcdhError` for a protocol version, curve, algorithm or key derivation that is not implemented. `exportPublicKey`, `importPublicKey` and `createServerHello` are available for a handshake with its own message format.

<Warning>
  The key exchange is not authenticated. `ServerHello.signatureB64` is neither created nor verified, and there is no key confirmation. The exchange protects against a party that can only read the connection. A party that can change messages can replace both public keys. An application that needs more has to authenticate the hello messages itself (for example by signing them with a key the client pins) or rely on TLS for the identity of the server.
</Warning>

### Key Derivation (HKDF)

```typescript
import { deriveKey, deriveSessionKeys, deriveSessionCryptoKeys } from '@enclave-vm/stream';

// Two keys, one per direction, as raw bytes
const { clientToServerKey, serverToClientKey } = await deriveSessionKeys(sharedSecret, sessionId);

// The same two keys as non-extractable CryptoKey objects
const cryptoKeys = await deriveSessionCryptoKeys(sharedSecret, sessionId);

// HKDF-SHA-256 with your own salt and info string (32 bytes by default)
const key = await deriveKey(sharedSecret, salt, 'my-application-key');
```

Use each key for one direction only.

### Encryption/Decryption (AES-GCM)

```typescript
import {
  SessionEncryptionContext,
  createEncryptedEnvelope,
  openEncryptedEnvelope,
  encryptJson,
  decryptJson,
} from '@enclave-vm/stream';

// One context per direction: the sender of a direction and its receiver
// each create a context from the key of that direction
const sender = await SessionEncryptionContext.fromKeyBytes(serverToClientKey, keyId);
const receiver = await SessionEncryptionContext.fromKeyBytes(serverToClientKey, keyId);

// Wrap an event in an `enc` envelope
const envelope = await sender.createEnvelope(sessionId, seq, event);

// Open it. Throws AesGcmError when the ciphertext or a header field of the
// envelope (protocol version, session id, sequence number, key id) differs.
const inner = await receiver.openEnvelope(envelope);

// The same with the CryptoKey objects of deriveSessionCryptoKeys()
const envelope2 = await createEncryptedEnvelope(cryptoKeys.serverToClientKey, keyId, sessionId, seq, event);
const inner2 = await openEncryptedEnvelope(cryptoKeys.serverToClientKey, envelope2);

// Payloads without an envelope, with optional additional authenticated data
const payload = await encryptJson(cryptoKeys.serverToClientKey, keyId, { data: 'secret' }, undefined, aad);
const data = await decryptJson(cryptoKeys.serverToClientKey, payload, aad);
```

- **Envelopes authenticate their header.** `createEncryptedEnvelope` and `context.createEnvelope` authenticate the protocol version, session id, sequence number and key id together with the event. Read envelopes with `openEncryptedEnvelope` or `context.openEnvelope`.
- **`decryptJson` does not open an envelope.** `decryptJson(key, payload)` and `context.decryptJson(payload)` read payloads made by `encryptJson`. Both forms of `encryptJson` and `decryptJson` take optional additional authenticated data.
- **Replays are for the receiver to detect.** Opening an envelope does not tell whether its sequence number was seen before. Compare it with the last one received, for example with [`SequenceTracker`](#sequence-tracking).
- **A context has a message limit.** `SessionEncryptionContext` uses a counter nonce (8 random bytes per context and a 32-bit counter) and refuses to encrypt after 2^30 messages; `needsRotation()` then returns `true`. There is no rotation: exchange keys again.
- **`toKeyInfo()` returns the raw key bytes.** Treat its result as the key itself.

The lower-level functions `encrypt`, `decrypt`, `generateNonce`, `generateCounterNonce`, `toBase64`, `fromBase64` and `encodeEnvelopeHeader` are exported as well. `generateCounterNonce` throws for a counter outside 0 to 2^32 - 1, and `fromBase64` throws `AesGcmError` on malformed input.

## Reconnection Handling

Helpers for a connection that the application opens itself: a state machine with exponential backoff, sequence tracking, an event buffer and a heartbeat monitor. They keep state and compute delays; they do not open connections.

### Connection State Machine

```typescript
import { ConnectionState, ReconnectionStateMachine } from '@enclave-vm/stream';

// Connection states
ConnectionState.Disconnected  // Not connected
ConnectionState.Connecting    // Connection in progress
ConnectionState.Connected     // Active connection
ConnectionState.Reconnecting  // Connection lost, a retry is scheduled
ConnectionState.Failed        // Retries exhausted, or a fatal error
ConnectionState.Closed        // Closed on purpose

// State machine
const stateMachine = new ReconnectionStateMachine({
  config: { maxRetries: 5, initialDelayMs: 1000, maxDelayMs: 30000, backoffMultiplier: 2 },
  onEvent: (event) => {
    switch (event.type) {
      case 'state_change':
        console.log(`Connection: ${event.previousState} -> ${event.state}`);
        break;
      case 'retry_scheduled':
        console.log(`Reconnection attempt ${event.attempt} in ${event.delayMs}ms`);
        break;
      case 'failed':
        console.error('Connection failed:', event.reason);
        break;
    }
  },
});

// Report what happens to the connection
stateMachine.connect();                       // -> Connecting
stateMachine.onConnected();                   // -> Connected
stateMachine.onDisconnected('socket closed'); // -> Reconnecting, then Connecting after the delay
stateMachine.onFatalError('unauthorized');    // -> Failed
stateMachine.close();                         // -> Closed
```

Open the connection when the state changes to `Connecting`.

### Reconnection Configuration

```typescript
import {
  DEFAULT_RECONNECTION_CONFIG,
  type ReconnectionConfig,
} from '@enclave-vm/stream';

const config: ReconnectionConfig = {
  maxRetries: 5,           // Max reconnection attempts
  initialDelayMs: 1000,    // Initial delay (ms)
  maxDelayMs: 30000,       // Max delay between attempts (ms)
  backoffMultiplier: 2,    // Exponential backoff multiplier
  jitter: true,            // Add random jitter to the delay
  jitterFactor: 0.3,       // Jitter factor (0-1)
};

console.log(DEFAULT_RECONNECTION_CONFIG); // The values above
```

### Sequence Tracking

```typescript
import { SequenceTracker } from '@enclave-vm/stream';

const tracker = new SequenceTracker();

// Track the sequence number of each received event
const { gap, missingStart, missingEnd } = tracker.receive(event.seq);
if (gap) {
  console.log(`Missing events ${missingStart} to ${missingEnd}`);
}

// Gaps seen so far
if (tracker.hasGaps()) {
  console.log('Missing events:', tracker.getGaps()); // [{ start, end }, ...]
}

// Get last received sequence
const lastSeq = tracker.getLastSeq();
```

`receive()` takes the first sequence number as the starting point, and answers `{ gap: false }` for a number at or below the last one. To detect a duplicate, compare the number with `getLastSeq()` before calling `receive()`.

### Event Buffering

```typescript
import { EventBuffer } from '@enclave-vm/stream';

const buffer = new EventBuffer(1000); // Max events to buffer (default 1000)

// Buffer events during disconnection; returns false when the buffer is full
const stored = buffer.add(event);

// Get buffered events for replay
const events = buffer.drain();

// Check buffer status
console.log(buffer.size());
console.log(buffer.isFull());
```

### Heartbeat Monitoring

```typescript
import { HeartbeatMonitor } from '@enclave-vm/stream';

const monitor = new HeartbeatMonitor({
  timeoutMs: 45000, // Silence before the connection is considered dead (ms)
  onTimeout: () => {
    console.log('Connection appears dead, reconnecting...');
  },
});

// Call when heartbeat received
monitor.onHeartbeat();

// Start/stop monitoring
monitor.start();
monitor.stop();
```
