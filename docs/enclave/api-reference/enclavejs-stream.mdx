API reference for the `@enclave-vm/stream` package - streaming protocol building blocks: NDJSON parsing, reconnection helpers, and encryption primitives.

<Warning>
  No EnclaveJS package uses the encryption primitives of this package. `@enclave-vm/client`, `@enclave-vm/react`, `@enclave-vm/broker` and `@enclave-vm/runtime` do not encrypt, perform no handshake and have no encryption option. A session between the client and the broker is plain JSON protected only by the transport, so serve it over HTTPS.
</Warning>

## Installation

```bash
npm install @enclave-vm/stream
```

## NDJSON Parsing

### serializeEvent(event)

Serialize an event to NDJSON format (single line, no trailing newline).

```ts
function serializeEvent(event: MaybeEncrypted<StreamEvent>): string
```

**Example:**
```ts
import { serializeEvent } from '@enclave-vm/stream';

const line = serializeEvent({
  protocolVersion: 2,
  sessionId: 's_123',
  seq: 1,
  type: 'stdout',
  payload: { chunk: 'Hello' }
});
// '{"protocolVersion":2,"sessionId":"s_123","seq":1,"type":"stdout","payload":{"chunk":"Hello"}}'
```

### serializeEvents(events)

Serialize multiple events to NDJSON format.

```ts
function serializeEvents(events: MaybeEncrypted<StreamEvent>[]): string
```

**Example:**
```ts
import { serializeEvents } from '@enclave-vm/stream';

const ndjson = serializeEvents([event1, event2, event3]);
// Each event on its own line
```

### parseLine(line)

Parse a single NDJSON line into an event. The line is validated against the event schemas of `@enclave-vm/types`.

```ts
function parseLine(line: string): ParseResult<ParsedStreamEvent | ParsedEncryptedEnvelope>

type ParseResult<T> =
  | { success: true; data: T }
  | { success: false; error: string; line: string };
```

**Example:**
```ts
import { parseLine } from '@enclave-vm/stream';

const result = parseLine('{"protocolVersion":2,"sessionId":"s_123","seq":1,"type":"stdout","payload":{"chunk":"Hi"}}');
if (result.success) {
  console.log(result.data.type); // 'stdout'
}
```

### parseLines(data)

Parse multiple NDJSON lines into events.

```ts
function parseLines(data: string): {
  events: (ParsedStreamEvent | ParsedEncryptedEnvelope)[];
  errors: Array<{ line: number; error: string; content: string }>;
}
```

**Example:**
```ts
import { parseLines } from '@enclave-vm/stream';

const { events, errors } = parseLines(ndjsonData);
console.log(`Parsed ${events.length} events, ${errors.length} errors`);
```

### NdjsonParseOptions

Options of the incremental parsers (`NdjsonStreamParser`, `createNdjsonParseStream`, `parseNdjsonStream`).

```ts
interface NdjsonParseOptions {
  maxLineLength?: number;
}

const DEFAULT_MAX_LINE_LENGTH = 8 * 1024 * 1024; // 8 MiB
```

| Property | Type | Default | Description |
|----------|------|---------|-------------|
| `maxLineLength` | `number` | `DEFAULT_MAX_LINE_LENGTH` | Maximum length of one line, in characters. A parser never holds more than this of a line that has not ended. A value that is not a positive integer throws a `RangeError` |

### NdjsonStreamParser

Incremental NDJSON parser for streaming data. Handles partial lines across chunks.

```ts
class NdjsonStreamParser {
  constructor(options: {
    onEvent: (event: ParsedStreamEvent | ParsedEncryptedEnvelope) => void;
    onError: (error: { line: number; error: string; content: string }) => void;
  } & NdjsonParseOptions);

  feed(chunk: string): void;
  flush(): void;
  reset(): void;
  getLineNumber(): number;
  hasPendingData(): boolean;
}
```

A line that is not a valid event is reported through `onError`. A line longer than `maxLineLength` is reported through `onError` once and skipped.

**Example:**
```ts
import { NdjsonStreamParser } from '@enclave-vm/stream';

const parser = new NdjsonStreamParser({
  onEvent: (event) => console.log('Event:', event.type),
  onError: (error) => console.error('Parse error:', error.error),
});

// Feed chunks as they arrive
parser.feed('{"protocolVersion":2,"sessionId":"s_123"');
parser.feed(',"seq":1,"type":"stdout","payload":{"chunk":"Hi"}}\n');

// Flush any remaining data when stream ends
parser.flush();
```

### createNdjsonParseStream(options?)

Create a transform stream that parses NDJSON. Works with browser `fetch()` and Node.js streams.

```ts
function createNdjsonParseStream(
  options?: NdjsonParseOptions
): TransformStream<string, ParsedStreamEvent | ParsedEncryptedEnvelope>
```

A line that is not a valid event is dropped. A line longer than `maxLineLength` ends the stream with an `NdjsonLineTooLongError`.

**Example:**
```ts
import { createNdjsonParseStream } from '@enclave-vm/stream';

const response = await fetch('/api/stream');
if (!response.body) throw new Error('No response body');

const reader = response.body
  .pipeThrough(new TextDecoderStream())
  .pipeThrough(createNdjsonParseStream())
  .getReader();

while (true) {
  const { done, value } = await reader.read();
  if (done) break;
  console.log('Event:', value.type);
}
```

### createNdjsonSerializeStream()

Create a transform stream that serializes events to NDJSON.

```ts
function createNdjsonSerializeStream(): TransformStream<MaybeEncrypted<StreamEvent>, string>
```

### parseNdjsonStream(stream, options?)

Async generator that parses NDJSON from a ReadableStream.

```ts
function parseNdjsonStream(
  stream: ReadableStream<Uint8Array>,
  options?: NdjsonParseOptions
): AsyncGenerator<ParsedStreamEvent | ParsedEncryptedEnvelope>
```

A line that is not a valid event is skipped. A line longer than `maxLineLength` ends the iteration with an `NdjsonLineTooLongError` and cancels the stream.

**Example:**
```ts
import { parseNdjsonStream } from '@enclave-vm/stream';

const response = await fetch('/api/stream');
if (!response.body) throw new Error('No response body');

for await (const event of parseNdjsonStream(response.body)) {
  console.log('Event:', event.type);
}
```

### NdjsonLineTooLongError

A line of the stream is longer than the parser's `maxLineLength`.

```ts
class NdjsonLineTooLongError extends Error {
  readonly maxLineLength: number;
  constructor(maxLineLength: number);
}
```

## ECDH Key Exchange

<Warning>
  The key exchange is not authenticated. `ServerHello.signatureB64` is neither created nor verified, and there is no key confirmation. The exchange protects against a party that can only read the connection. A party that can change messages can replace both public keys. An application that needs more has to authenticate the hello messages itself (for example by signing them with a key the client pins) or rely on TLS for the identity of the server.
</Warning>

### generateKeyPair(curve?)

Generate an ephemeral ECDH key pair. The private key cannot be exported.

```ts
async function generateKeyPair(curve?: SupportedCurve): Promise<EcdhKeyPair>

interface EcdhKeyPair {
  publicKey: CryptoKey;
  privateKey: CryptoKey;
}
```

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `curve` | `SupportedCurve` | `'P-256'` | Elliptic curve to use. `SupportedCurve` has one value, `'P-256'`, and the hello functions refuse any other curve |

**Example:**
```ts
import { generateKeyPair } from '@enclave-vm/stream';

const keyPair = await generateKeyPair();
```

### exportPublicKey(publicKey)

Export a public key to base64 format.

```ts
async function exportPublicKey(publicKey: CryptoKey): Promise<SerializedPublicKey>

interface SerializedPublicKey {
  publicKeyB64: string;
  curve: SupportedCurve;
}
```

### importPublicKey(publicKeyB64, curve?)

Import a public key from base64 format.

```ts
async function importPublicKey(
  publicKeyB64: string,
  curve?: SupportedCurve
): Promise<CryptoKey>
```

### deriveSharedSecret(privateKey, peerPublicKey)

Derive shared secret from private key and peer's public key.

```ts
async function deriveSharedSecret(
  privateKey: CryptoKey,
  peerPublicKey: CryptoKey
): Promise<Uint8Array>
```

**Example:**
```ts
import { generateKeyPair, deriveSharedSecret, importPublicKey } from '@enclave-vm/stream';

// Client side
const clientKeyPair = await generateKeyPair();
const serverPubKey = await importPublicKey(serverPublicKeyB64);
const sharedSecret = await deriveSharedSecret(clientKeyPair.privateKey, serverPubKey);
```

### createClientHello(keyPair)

Create a client hello message for the encryption handshake.

```ts
async function createClientHello(keyPair: EcdhKeyPair): Promise<ClientHello>
```

### createServerHello(keyPair, keyId)

Create a server hello message for the encryption handshake. The message has no `signatureB64`.

```ts
async function createServerHello(keyPair: EcdhKeyPair, keyId: string): Promise<ServerHello>
```

### processClientHello(clientHello)

Process a client hello and generate server response: the server's ephemeral key pair, a key id, and the server hello. Nothing here proves who sent the hello.

Throws `EcdhError` when the hello names a protocol version, curve or algorithm that is not implemented.

```ts
async function processClientHello(clientHello: ClientHello): Promise<{
  serverKeyPair: EcdhKeyPair;
  peerPublicKey: CryptoKey;
  serverHello: ServerHello;
  keyId: string;
}>
```

### processServerHello(serverHello)

Process a server hello and extract peer's public key. `signatureB64` is not verified: the public key is only as trustworthy as the connection it arrived on.

Throws `EcdhError` when the hello names a protocol version, curve, algorithm or key derivation that is not implemented, or has no key id.

```ts
async function processServerHello(serverHello: ServerHello): Promise<{
  peerPublicKey: CryptoKey;
  keyId: string;
}>
```

### EcdhError

Error class for ECDH operations.

```ts
class EcdhError extends Error {
  readonly code: string;
  constructor(message: string, code: string);
}
```

## Key Derivation (HKDF)

### deriveKey(sharedSecret, salt, info, keyLength?)

Derive a key using HKDF-SHA256.

```ts
async function deriveKey(
  sharedSecret: Uint8Array,
  salt: Uint8Array | null,
  info: string,
  keyLength?: number
): Promise<Uint8Array>
```

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `sharedSecret` | `Uint8Array` | Required | Shared secret from ECDH |
| `salt` | `Uint8Array \| null` | Required | Salt (`null` uses 32 zero bytes) |
| `info` | `string` | Required | Context info string |
| `keyLength` | `number` | `32` | Output key length in bytes |

### deriveSessionKeys(sharedSecret, sessionId)

Derive session keys for bidirectional communication: two keys, one per direction. The result holds raw key bytes.

```ts
async function deriveSessionKeys(
  sharedSecret: Uint8Array,
  sessionId: string
): Promise<{
  clientToServerKey: Uint8Array;
  serverToClientKey: Uint8Array;
}>
```

Import raw key bytes as a non-extractable CryptoKey for AES-GCM.

```ts
async function importAesGcmKey(keyBytes: Uint8Array): Promise<CryptoKey>
```

### deriveSessionCryptoKeys(sharedSecret, sessionId)

Derive and import session keys as CryptoKeys.

```ts
async function deriveSessionCryptoKeys(
```

## AES-GCM Encryption

### encrypt(key, plaintext, nonce, additionalData?)

Encrypt data using AES-GCM. Returns the ciphertext with the authentication tag appended.

```ts
async function encrypt(
  key: CryptoKey,
  plaintext: Uint8Array,
  nonce: Uint8Array,
  additionalData?: Uint8Array
): Promise<Uint8Array>
```

### decrypt(key, ciphertext, nonce, additionalData?)

Decrypt data using AES-GCM.

```ts
async function decrypt(
  key: CryptoKey,
  ciphertext: Uint8Array,
  nonce: Uint8Array,
  additionalData?: Uint8Array
): Promise<Uint8Array>
```

### encryptJson(key, keyId, data, nonce?, additionalData?)

Encrypt a JSON object and create an encrypted envelope payload. A random nonce is generated when none is given.

```ts
async function encryptJson(
  key: CryptoKey,
  keyId: string,
  data: unknown,
  nonce?: Uint8Array,
  additionalData?: Uint8Array
): Promise<EncryptedEnvelopePayload>
```

### decryptJson(key, payload, additionalData?)

Decrypt a payload made by `encryptJson` and parse it as JSON. Pass the additional authenticated data that was given to `encryptJson`, if any.

This does not open an envelope: the payload of an envelope is read with `openEncryptedEnvelope`, which also checks the envelope's header.

```ts
async function decryptJson<T>(
  key: CryptoKey,
  payload: EncryptedEnvelopePayload,
  additionalData?: Uint8Array
): Promise<T>
```

### createEncryptedEnvelope(key, keyId, sessionId, seq, innerEvent, nonce?)

Create an encrypted envelope from an event. The envelope's header (protocol version, session id, sequence number, key id) is authenticated together with the event.

```ts
async function createEncryptedEnvelope(
  key: CryptoKey,
  keyId: string,
  sessionId: SessionId,
  seq: number,
  innerEvent: unknown,
  nonce?: Uint8Array
): Promise<EncryptedEnvelope>
```

### openEncryptedEnvelope(key, envelope)

Decrypt an encrypted envelope and parse the event inside it.

Throws `AesGcmError` when the ciphertext or any header field of the envelope (protocol version, session id, sequence number, key id) is not what the sender encrypted. Whether a sequence number was seen before is for the caller to check, for example with `SequenceTracker`.

```ts
async function openEncryptedEnvelope<T>(key: CryptoKey, envelope: EnvelopeLike): Promise<T>

interface EnvelopeLike {
  protocolVersion: number;
  sessionId: string;
  seq: number;
  payload: EncryptedEnvelopePayload;
}
```

**Example:**
```ts
import { deriveSessionCryptoKeys, createEncryptedEnvelope, openEncryptedEnvelope } from '@enclave-vm/stream';

const { serverToClientKey } = await deriveSessionCryptoKeys(sharedSecret, 's_123');

const envelope = await createEncryptedEnvelope(serverToClientKey, keyId, 's_123', 1, {
  type: 'stdout',
  payload: { chunk: 'Hello' }
});

const event = await openEncryptedEnvelope(serverToClientKey, envelope);
```

### encodeEnvelopeHeader(header)

Encode an envelope header as the additional authenticated data that the envelope functions pass to AES-GCM. Throws `AesGcmError` when a field is not of its type.

```ts
function encodeEnvelopeHeader(header: EnvelopeHeader): Uint8Array

interface EnvelopeHeader {
  protocolVersion: number;
  sessionId: string;
  seq: number;
  kid: string;
}
```

## SessionEncryptionContext

Manages encryption key state for one direction of a session. `deriveSessionKeys` gives two keys, one per direction: use one context per direction, never one context for both.

```ts
class SessionEncryptionContext {
  constructor(key: CryptoKey, keyInfo: SessionKeyInfo);

  // Properties
  readonly keyId: string;

  // Methods
  needsRotation(): boolean;
  encrypt(plaintext: Uint8Array, additionalData?: Uint8Array): Promise<{ ciphertext: Uint8Array; nonce: Uint8Array }>;
  encryptJson(data: unknown, additionalData?: Uint8Array): Promise<EncryptedEnvelopePayload>;
  createEnvelope(sessionId: SessionId, seq: number, innerEvent: unknown): Promise<EncryptedEnvelope>;
  decrypt(payload: EncryptedEnvelopePayload, additionalData?: Uint8Array): Promise<Uint8Array>;
  decryptJson<T>(payload: EncryptedEnvelopePayload, additionalData?: Uint8Array): Promise<T>;
  openEnvelope<T>(envelope: EnvelopeLike): Promise<T>;
  getNonceCounter(): bigint;
  toKeyInfo(): SessionKeyInfo;

  // Static methods
  static fromKeyBytes(keyBytes: Uint8Array, keyId: string): Promise<SessionEncryptionContext>;
}
```

- `createEnvelope` authenticates the envelope's header (protocol version, session id, sequence number, key id) together with the event. Read envelopes with `openEnvelope`, which throws `AesGcmError` when the ciphertext or a header field differs. Whether a sequence number was seen before is for the caller to check.
- `decrypt` and `decryptJson` read payloads made by `encrypt` and `encryptJson`. They do not open an envelope.
- The nonce is 8 random bytes chosen per context followed by a 32-bit counter.
- A context made by `fromKeyBytes` refuses to encrypt after 2^30 messages (`MAX_MESSAGES_PER_KEY`): `needsRotation()` returns `true` and `encrypt` throws `AesGcmError`. There is no rotation: exchange keys again.
- `toKeyInfo()` returns the raw key bytes. Treat its result as the key itself.

**Example:**
```ts
import { SessionEncryptionContext, deriveSessionKeys } from '@enclave-vm/stream';

const { serverToClientKey } = await deriveSessionKeys(sharedSecret, 's_123');

// One context on each side of a direction, from that direction's key
const sender = await SessionEncryptionContext.fromKeyBytes(serverToClientKey, 'key_123');
const receiver = await SessionEncryptionContext.fromKeyBytes(serverToClientKey, 'key_123');

// Encrypt an event
const envelope = await sender.createEnvelope('s_123', 1, {
  type: 'stdout',
  payload: { chunk: 'Hello' }
});

// Check if the message limit of the key is reached
if (sender.needsRotation()) {
  // Exchange keys again
}

// Decrypt
const decrypted = await receiver.openEnvelope(envelope);
```

## Reconnection

### ConnectionState

Connection state enumeration.

```ts
const ConnectionState = {
  Disconnected: 'disconnected',
  Connecting: 'connecting',
  Connected: 'connected',
  Reconnecting: 'reconnecting',
  Failed: 'failed',
  Closed: 'closed',
} as const;

type ConnectionState = (typeof ConnectionState)[keyof typeof ConnectionState];
```

### DEFAULT_RECONNECTION_CONFIG

Default reconnection configuration.

```ts
const DEFAULT_RECONNECTION_CONFIG: ReconnectionConfig = {
  maxRetries: 5,
  initialDelayMs: 1000,
  maxDelayMs: 30000,
  backoffMultiplier: 2,
  jitter: true,
  jitterFactor: 0.3,
};

interface ReconnectionConfig {
  maxRetries: number;
  initialDelayMs: number;
  maxDelayMs: number;
  backoffMultiplier: number;
  jitter: boolean;
  jitterFactor: number;
}
```

### ReconnectionStateMachine

Manages connection state and automatic reconnection.

```ts
class ReconnectionStateMachine {
  constructor(options: {
    config?: Partial<ReconnectionConfig>;
    onEvent: (event: ReconnectionEvent) => void;
  });

  getState(): ConnectionState;
  getRetryCount(): number;
  connect(): void;
  onConnected(): void;
  onDisconnected(reason?: string): void;
  onFatalError(reason: string): void;
  close(): void;
  reset(): void;
  canReconnect(): boolean;
}

type ReconnectionEvent =
  | { type: 'state_change'; state: ConnectionState; previousState: ConnectionState }
  | { type: 'retry_scheduled'; attempt: number; delayMs: number }
  | { type: 'retry_started'; attempt: number }
  | { type: 'connected' }
  | { type: 'disconnected'; reason?: string }
  | { type: 'failed'; reason: string };
```

**Example:**
```ts
import { ReconnectionStateMachine, ConnectionState } from '@enclave-vm/stream';

const reconnect = new ReconnectionStateMachine({
  config: { maxRetries: 3 },
  onEvent: (event) => {
    switch (event.type) {
      case 'state_change':
        console.log(`State: ${event.previousState} -> ${event.state}`);
        break;
      case 'retry_scheduled':
        console.log(`Retry ${event.attempt} in ${event.delayMs}ms`);
        break;
      case 'connected':
        console.log('Connected!');
        break;
      case 'failed':
        console.error('Connection failed:', event.reason);
        break;
    }
  },
});

reconnect.connect();
// ... when connection succeeds
reconnect.onConnected();
// ... when connection drops
reconnect.onDisconnected('Network error');
```

### SequenceTracker

Tracks sequence numbers and detects gaps for replay.

```ts
class SequenceTracker {
  constructor(maxGaps?: number);

  receive(seq: number): { gap: boolean; missingStart?: number; missingEnd?: number };
  getLastSeq(): number;
  getGaps(): Array<{ start: number; end: number }>;
  clearGap(start: number, end: number): void;
  hasGaps(): boolean;
  reset(): void;
}
```

`receive()` answers `{ gap: false }` for a sequence number at or below the last one. To detect a duplicate, compare the number with `getLastSeq()` before calling `receive()`.

**Example:**
```ts
import { SequenceTracker } from '@enclave-vm/stream';

const tracker = new SequenceTracker();

tracker.receive(1); // { gap: false }
tracker.receive(2); // { gap: false }
tracker.receive(5); // { gap: true, missingStart: 3, missingEnd: 4 }

console.log(tracker.getGaps()); // [{ start: 3, end: 4 }]
```

### EventBuffer

Buffer for storing events during reconnection.

```ts
class EventBuffer {
  constructor(maxSize?: number);

  add(event: StreamEvent | EncryptedEnvelope): boolean;
  getAll(): (StreamEvent | EncryptedEnvelope)[];
  drain(): (StreamEvent | EncryptedEnvelope)[];
  size(): number;
  isFull(): boolean;
  clear(): void;
}
```

**Example:**
```ts
import { EventBuffer } from '@enclave-vm/stream';

```

### HeartbeatMonitor

Monitors heartbeats to detect stale connections.

```ts
class HeartbeatMonitor {
  constructor(options: { timeoutMs: number; onTimeout: () => void });

  start(): void;
  stop(): void;
  reset(): void;
  onHeartbeat(): void;
  getTimeSinceLastHeartbeat(): number;
}
```

**Example:**
```ts
import { HeartbeatMonitor } from '@enclave-vm/stream';

const monitor = new HeartbeatMonitor({
  timeoutMs: 30000,
  onTimeout: () => {
    console.log('Connection stale, reconnecting...');
    reconnect();
  },
});

monitor.start();

// When heartbeat received
monitor.onHeartbeat();

// When done
monitor.stop();
```
